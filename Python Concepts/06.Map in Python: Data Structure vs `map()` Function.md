# Map in Python: Data Structure vs `map()` Function

The word **"Map"** in Python can refer to **two completely different things**, depending on the context.

- **Map as a Data Structure** → A collection of **key-value pairs** (implemented using Python's `dict`).
- **`map()` as a Built-in Function** → A function that applies another function to every element of an iterable.

Understanding the difference is important, especially in Data Structures & Algorithms (DSA) and Python programming.

---

# 1. "Map" as a Data Structure (Yes, it's a Dictionary!)

When computer scientists or interviewers talk about a **"Map"**, **"Hash Map"**, or **"Hash Table"** as a data structure, they are talking about a collection of **Key-Value pairs**.

In Python, the built-in data structure used to implement a **Hash Map** is the **Dictionary (`dict`)**.

So, if someone says:

- "Use a map to solve this."
- "Store the frequencies in a hash map."

they simply mean using a Python dictionary.

### Example

```python
# This is Python's implementation of a Map / Hash Map
my_map = {
    "apple": 1,
    "banana": 2
}
```

---

## Why use it?

Lookups, insertions, and deletions in a Python dictionary take **O(1)** (constant) time on average, making it an extremely fast data structure.

---

# 2. `map()` as a Built-In Function

Python also has a specific, built-in function actually called `map()`.

This has **nothing to do** with the dictionary data structure.

The `map(function, iterable)` function takes another function and applies it to every single item inside a list (or any iterable).

---

## Example

Suppose you have a list of numbers and want to square all of them.

```python
nums = [1, 2, 3, 4]

# A simple function to square a number
def square(x):
    return x * x

# Apply the 'square' function to every item in 'nums'
squared_nums = list(map(square, nums))

print(squared_nums)
# Output: [1, 4, 9, 16]
```

---

# Summary

- If someone is talking about **Data Structures & Algorithms (DSA)**, a **"Map"** refers to a **Dictionary (`dict`)**.
- If someone is talking about **Functional Programming**, **`map()`** is a built-in function that applies a function to every element of an iterable.
