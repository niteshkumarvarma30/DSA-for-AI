# Union of 2 Sorted Arrays

## Concepts & Explanation
The union of two arrays is an array containing all unique elements that exist in either of the original arrays. Since the two input arrays are sorted, we can efficiently find their union using a **Two Pointer Approach**.

### Approach
- **Two Pointers**: We initialize two pointers, `i` to traverse array `a`, and `j` to traverse array `b`. Both start at index `0`.
- **Simultaneous Traversal**: We iterate through both arrays simultaneously as long as both pointers are within bounds (`i < n` and `j < m`).
- **Comparison**: At each step, we compare the elements `a[i]` and `b[j]`. We pick the smaller element to add to our result array `res`, as this guarantees we add elements in sorted order. If `a[i] <= b[j]`, we consider `a[i]` and increment `i`. If `b[j] < a[i]`, we consider `b[j]` and increment `j`.
- **Handling Duplicates**: The crucial part is avoiding duplicate entries in our result. Before we append the chosen element to `res`, we check if the result array is either empty (`len(res) == 0`) or if the last element added is different from the current element (`res[-1] != chosen_element`). If it's a duplicate, we just move our pointer without appending.
- **Remaining Elements**: After the main loop, one of the arrays might still have unprocessed elements (if one was longer or had much larger elements). We run two separate `while` loops to simply append the rest of the elements from the non-exhausted array, again ensuring we don't add consecutive duplicates.

### Complexity
- **Time Complexity**: $O(N + M)$ where $N$ and $M$ are the lengths of the two arrays. Both arrays are traversed at most once.
- **Space Complexity**: $O(N + M)$ for the result array in the worst case (if all elements in both arrays are unique). Excluding the output space, the auxiliary space is $O(1)$.

## Code
```python
class Solution:
    def findUnion(self, a, b):
        # code here 
        n = len(a)
        m = len(b)
        res = []
        i = 0
        j = 0
        while i < n and j < m:
            if a[i] <= b[j]:
                if len(res) == 0 or res[-1] != a[i]:
                    res.append(a[i])
                i += 1
            else:
                if len(res) == 0 or res[-1] != b[j]:
                    res.append(b[j])  
                j += 1
                
        # Handle remaining elements in array 'a'
        while i < n:
            if len(res) == 0 or res[-1] != a[i]:
                res.append(a[i])
            i += 1    
            
        # Handle remaining elements in array 'b'
        while j < m:
            if len(res) == 0 or res[-1] != b[j]:
                res.append(b[j])
            j += 1  
            
        return res   
```
