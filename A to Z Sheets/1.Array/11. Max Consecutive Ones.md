# Max Consecutive Ones

## Concepts & Explanation
The goal is to find the maximum number of consecutive `1`s in a binary array (an array containing only `0`s and `1`s). This can be solved very efficiently with a single pass through the array using a counting technique.

### Approach
- **Counters**: We need two integer variables:
  - `cnt`: To keep track of the length of the *current* streak of consecutive `1`s.
  - `max_cnt`: To store the *maximum* streak of `1`s found anywhere in the array so far.
- **Iteration Strategy**: We loop through each element in the array `nums`.
  - **Case 1: The element is `1`**. The streak continues, so we simply increment our current streak counter (`cnt += 1`).
  - **Case 2: The element is `0`**. The streak is broken. 
    - Before resetting, we update our `max_cnt` by checking if the streak that just ended (`cnt`) is larger than our previous `max_cnt` (`max_cnt = max(max_cnt, cnt)`).
    - Then, we reset the current streak counter (`cnt = 0`) so it's ready to start counting the next group of `1`s.
- **Final Check**: After the loop finishes, we must return `max(max_cnt, cnt)`. Why? Because if the longest sequence of `1`s occurs at the very end of the array, the loop will terminate without ever hitting a `0` to trigger the final `max_cnt` update. This final check ensures we don't miss a trailing streak.

### Complexity
- **Time Complexity**: $O(N)$, where $N$ is the number of elements in the array. We iterate through the array exactly once.
- **Space Complexity**: $O(1)$, because we only use two variables to maintain counts, which takes constant extra space regardless of how large the input array is.

## Code
```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        
        cnt = 0
        max_cnt = 0
        n = len(nums)
        for i in range(n):
            if nums[i] == 1:
                cnt += 1
            else:
                max_cnt = max(max_cnt, cnt)
                cnt = 0
        return max(max_cnt, cnt)     
```
