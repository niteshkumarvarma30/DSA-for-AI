# Check if Array Is Sorted and Rotated

## Concepts & Explanation
- **Circular Array Simulation**: A sorted array that has been rotated will still have its elements in a sorted order if we consider the array to be circular. By looping up to $2 \times N$ times, we can simulate reading the array wrap-around.
- **Modulo Operator (`% N`)**: We use modulo arithmetic for the indices (`(i - 1) % N` and `i % N`) to continuously wrap around the boundaries of the array seamlessly without going out of bounds.
- **Counting the Sorted Sequence**: We keep track of the `count` of consecutive non-decreasing elements. If the current element is greater than or equal to the previous element in our circular check, we increment `count`.
- **Resetting the Count**: If there's a dip (i.e., the current element is strictly less than the previous element), the sequence is broken, and we reset the `count` back to `1`.
- **Matching the Length**: If at any point the `count` becomes equal to $N$ (the total number of elements in the array), it means we have found a valid sorted sequence of length $N$ that wraps around. Thus, we can safely return `True`.
- **Edge Case**: If the loop finishes and we haven't found a sequence of length $N$, we return `True` only if $N == 1$ (an array with just 1 element is inherently sorted and rotated), otherwise we return `False`.
- **Time Complexity**: $O(N)$ because the loop iterates $2N$ times at most, resulting in linear time complexity.
- **Space Complexity**: $O(1)$ because we only use a few constant extra variables.

## Code
```python
class Solution:
    def check(self, nums: List[int]) -> bool:
        N = len(nums)
        count = 1
        for i in range(1, N * 2):
            if (nums[(i - 1) % N] <= nums[i % N]):
                count += 1
            else:
                count = 1
            if (count == N):
                return True

        return N == 1   
```
