# Single Number

## Concepts & Explanation
In this problem, every element in the array appears twice except for one. We need to find that single element.

The provided code demonstrates two different approaches:

### 1. Using a Dictionary / Hash Map (Brute Force)
- **Concept**: We can simply count how many times each number appears in the array. Since we know every number appears exactly twice except for the target number which appears once, we can find it by checking the counts.
- **Implementation**: 
  - We initialize an empty dictionary called `freq_map`.
  - We iterate through the array. For each number, if it's already a key in `freq_map`, we increment its count by 1. Otherwise, we add it with a count of 1.
  - After populating the counts, we iterate through the key-value pairs of the dictionary using `freq_map.items()`.
  - The first time we encounter a `value` (count) of `1`, we know its corresponding `key` (number) is the single number, and we return it.
- **Time Complexity**: $O(N)$ because populating the hash map takes linear time, and iterating through it takes linear time.
- **Space Complexity**: $O(N)$ because we allocate a dictionary that will grow proportionally to the size of the array (specifically, it will hold $\frac{N}{2} + 1$ unique items).

### 2. Using XOR Bitwise Operation (Optimal)
- **Concept**: This is the most optimal approach. It leverages the unique mathematical properties of the bitwise XOR (`^`) operator:
  1. **Self-Cancellation**: Any number XORed with itself is 0 (`a ^ a = 0`).
  2. **Identity Property**: Any number XORed with 0 remains unchanged (`a ^ 0 = a`).
  3. **Order Independence**: XOR is both commutative and associative, meaning the order in which we XOR the numbers doesn't matter.
  Because all other numbers appear exactly twice, they will cancel each other out and become `0` when XORed together. The only number left will be the single number (`0 ^ single_number = single_number`).
- **Implementation**: We initialize a variable `result = 0`. We loop through all the numbers in the array, continuously applying the XOR operation: `result ^= num`. When the loop finishes, `result` will be the single number.
- **Time Complexity**: $O(N)$ because we only need to iterate through the array once.
- **Space Complexity**: $O(1)$ because the calculation is done in-place using a single primitive variable, requiring no extra memory regardless of the array's size.
