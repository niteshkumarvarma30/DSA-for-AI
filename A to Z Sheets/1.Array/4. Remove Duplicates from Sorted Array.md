# Remove Duplicates from Sorted Array

## Concepts & Explanation
In this problem, we need to remove duplicates from a sorted array in-place, such that each unique element appears only once. The relative order of the elements should be kept the same, and we must return the number of unique elements.

The provided code demonstrates two different approaches:

### 1. Using a Set (Brute Force / Pythonic Way)
- **Concept**: A Python `set` automatically removes duplicate values. We can convert the array to a set, which leaves only unique elements, and then sort it to maintain the original sorted order (since sets are unordered).
- **Implementation**: We can update the original array in-place using slice assignment `nums[:] = sorted(set(nums))` and then return the new length.
- **Time Complexity**: $O(N \log N)$ due to the sorting step. Converting to a set takes $O(N)$, but sorting the unique elements takes $O(N \log N)$.
- **Space Complexity**: $O(N)$ because the `set` creates a new data structure in memory to hold the unique elements temporarily.

### 2. Two Pointer Approach (Optimal Strategy)
- **Concept**: Since the array is already sorted, all duplicate elements will naturally be adjacent to each other. We can use two pointers: one pointer (`i`) to iterate through the array, and another pointer (`k`) to keep track of the index where the next unique element should be placed.
- **Implementation**: 
  - We initialize `k = 1` because the very first element `nums[0]` is always unique by default.
  - We iterate with `i` from `0` to `len(nums) - 2` (comparing `nums[i]` and `nums[i+1]`).
  - If `nums[i] != nums[i+1]`, it signifies we have stumbled upon a new unique element. We place this new unique element `nums[i+1]` at the index `k`, and then increment `k`.
  - Finally, `k` will represent the total count of unique elements, and the first `k` slots of the array will contain these unique values.
- **Time Complexity**: $O(N)$ since we iterate through the array exactly once in a single pass.
- **Space Complexity**: $O(1)$ since the modifications are done entirely in-place without needing any additional data structures.

## Code
```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        # Using the set (Pythonic way)
        # nums[:] = sorted(set(nums))
        # return len(nums)

        # Using the two pointer approach (Optimal)
        k = 1
        for i in range(len(nums) - 1):
            if nums[i] != nums[i+1]:
                nums[k] = nums[i+1]
                k += 1
        return k        
```
