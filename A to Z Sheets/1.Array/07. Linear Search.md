# Linear Search

## Concepts & Explanation
Linear search is one of the simplest searching algorithms. It works by sequentially checking each element of a list until a match is found or the entire list has been searched.

### Approach
- **Iterative Check**: We iterate through the array starting from the first element (index `0`) to the last element (index `len(nums) - 1`).
- **Matching Condition**: At each step `i`, we compare the current element `nums[i]` with the `target` value.
- **Return Value**: 
  - If `nums[i] == target`, it means we have successfully found our target. We immediately return the current index `i`.
  - If the loop finishes executing and we still haven't found the target, it means the target does not exist in the array. In this case, we return `-1`.

### Complexity
- **Time Complexity**: $O(N)$ in the worst case (when the target is at the very end of the array, or not present at all, requiring us to traverse the entire array). The best-case time complexity is $O(1)$ if the target happens to be the first element.
- **Space Complexity**: $O(1)$ since the algorithm only requires a constant amount of extra space (just the loop variable `i`), regardless of the size of the input array.

## Code
```python
class Solution:
    def linearSearch(self, nums, target):
        for i in range(len(nums)):
            if nums[i] == target:
                return i

        return -1        
```
