# Missing Number

## Concepts & Explanation
The problem asks us to find the only missing number in an array containing $n$ distinct numbers taken from the range `0` to `n`. 

The provided code demonstrates two different approaches to solve this:

### 1. Mathematical Sum Approach (Optimal)
- **Concept**: If an array contains all numbers from `0` to `n` without any missing numbers, its total sum would be the sum of the first `n` natural numbers. The mathematical formula for the sum of the first $n$ natural numbers is $\frac{n \times (n+1)}{2}$. By subtracting the actual sum of the elements present in the array from this expected sum, the difference will exactly yield the missing number.
- **Implementation**: 
  - Compute the expected total sum using the formula: `summ = (n * (n + 1)) // 2`.
  - Iterate through the given array and calculate the actual sum of its elements (`nums_sum`).
  - Return the difference: `summ - nums_sum`.
- **Time Complexity**: $O(N)$ because we iterate through the array exactly once to calculate its sum.
- **Space Complexity**: $O(1)$ because we only use a couple of variables to store the sums, requiring constant extra space regardless of the array size.

### 2. Linear Search Approach (Brute Force)
- **Concept**: Since the numbers must be in the range from `0` to `n`, we can systematically check every single number in this range to see if it exists in the array.
- **Implementation**: We use a `for` loop from `0` to `n` (inclusive) and check `if i not in nums`. The first number `i` that is not found in the array is our missing number.
- **Time Complexity**: $O(N^2)$. The `in` operator for a list takes $O(N)$ time on average, and we execute it inside a loop that runs up to $N+1$ times in the worst case. 
- **Space Complexity**: $O(1)$ as no extra memory is dynamically allocated.

## Code
```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        # Using the mathematical sum (Optimal)
        n = len(nums)
        summ = (n * (n + 1)) // 2
        nums_sum = 0
        for i in nums:
            nums_sum += i
        return summ - nums_sum
```
