# Second Largest Element in an Array

## Concepts & Explanation
- **Edge Cases**: If the array has fewer than two elements, a second largest element cannot exist, so we return `-1`.
- **Initialization**: We keep track of two variables, `max_element` and `second_max`, both initialized to negative infinity (`float('-inf')`).
- **Single Pass Iteration**: By iterating through the array exactly once, we update the variables based on these conditions:
  - If the current element is greater than `max_element`, it becomes the new `max_element`, and the previous `max_element` gets demoted to `second_max`.
  - If the current element is not greater than `max_element` but is greater than `second_max` AND it is not equal to `max_element` (ensuring we find the *strictly* second largest), then it becomes the new `second_max`.
- **Return Condition**: Finally, if `second_max` was successfully updated (i.e., it's no longer negative infinity), we return it; otherwise, we return `-1`.
- **Time Complexity**: $O(N)$ because the array is traversed only once.
- **Space Complexity**: $O(1)$ because we only use two variables for tracking, regardless of array size.

## Code
```python
class Solution:
    def getSecondLargest(self, arr):
        # code here
        if len(arr)<2:
            return -1
        max_element=float('-inf')  
        second_max=float('-inf')
        for i in range(len(arr)):
            if arr[i]>max_element:
                second_max=max_element
                max_element=arr[i]
                
            elif arr[i]>second_max and arr[i]!=max_element:
                second_max=arr[i]
                
        return second_max if second_max!=float('-inf') else -1        
```
