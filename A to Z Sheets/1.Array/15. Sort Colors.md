# Sort Colors

## Concepts & Explanation
The problem requires us to sort an array consisting only of `0`s (representing red), `1`s (representing white), and `2`s (representing blue) in-place so that objects of the same color are adjacent, with the colors strictly in the order of `0`, `1`, and `2`.

The provided code demonstrates two different approaches:

### 1. Dutch National Flag Algorithm (Optimal / One-Pass)
- **Concept**: This is a classic algorithm proposed by Edsger W. Dijkstra. It partitions the array into three distinct sections using three pointers: `low`, `mid`, and `high`.
  - Everything from index `0` to `low - 1` will exclusively be `0`s.
  - Everything from index `low` to `mid - 1` will exclusively be `1`s.
  - Everything from index `mid` to `high` is unsorted (the region we are currently examining).
  - Everything from index `high + 1` to `n - 1` will exclusively be `2`s.
- **Implementation**: 
  - We initialize `low = 0`, `mid = 0`, and `high = len(nums) - 1`.
  - We iterate as long as `mid <= high` (meaning there are still unsorted elements left to evaluate).
  - We examine `nums[mid]`:
    - **If it is `0`**: We swap it with `nums[low]`. Since we know `nums[low]` was previously checked by `mid` (or they are at the same index), it is guaranteed to be a `1`. Thus, we can safely increment both `low` and `mid`.
    - **If it is `1`**: It's already in the correct middle section, so we simply increment `mid` to look at the next element.
    - **If it is `2`**: We swap it with `nums[high]`. We don't immediately know what the new element coming from `high` is, so we *only* decrement `high` and leave `mid` where it is. This allows the new element at `mid` to be evaluated on the next loop iteration.
- **Time Complexity**: $O(N)$ because we traverse the array in a single pass.
- **Space Complexity**: $O(1)$ because we only use three pointers, sorting the array completely in-place.

### 2. Counting Sort Approach (Two-Pass / Brute Force)
- **Concept**: Since there are only three distinct values in the entire array, we can simply count the total occurrences of each value and then overwrite the original array with those values in the correct order.
- **Implementation**:
  - **First Pass**: Iterate through the array and maintain three counters (`count0`, `count1`, `count2`) to count how many `0`s, `1`s, and `2`s exist.
  - **Second Pass**: Iterate through the array again, this time overwriting the elements in-place. We first write `0`s `count0` times, then `1`s `count1` times, and finally `2`s `count2` times.
- **Time Complexity**: $O(N) + O(N) = O(N)$. Although it operates in linear time, it requires traversing the entire array twice, making it slightly less optimal than the one-pass Dutch National Flag algorithm.
- **Space Complexity**: $O(1)$ because we only use three integer variables to keep track of the counts.

class Solution(object):
    def sortColors(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """
        # Using the Dutch National Flag algorithm (Optimal)
        n = len(nums)
        low = 0
        mid = 0
        high = n - 1
        
        while mid <= high:
            if nums[mid] == 0:
                nums[mid], nums[low] = nums[low], nums[mid]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:
