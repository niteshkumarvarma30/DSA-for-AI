# 560. Subarray Sum Equals K

**Difficulty:** Medium  
**Topics:** Array, Hash Table, Prefix Sum

## Problem Description
Given an array of integers `nums` and an integer `k`, return the total number of subarrays whose sum equals to `k`.

A subarray is a contiguous non-empty sequence of elements within an array.

### Examples

**Example 1:**
- **Input:** `nums = [1, 1, 1]`, `k = 2`
- **Output:** `2`

**Example 2:**
- **Input:** `nums = [1, 2, 3]`, `k = 3`
- **Output:** `2`

---

## Concepts & Explanation

The provided code demonstrates two different approaches to solving this problem:

### 1. Brute Force (Checking all subarrays)
- **Concept**: The most straightforward way to solve this is to generate all possible subarrays, calculate the sum of each, and count how many times the sum equals $k$.
- **Implementation**: We can use two nested loops. The outer loop `i` marks the starting index of the subarray. The inner loop `j` traverses from `i` to the end of the array, expanding the subarray. We keep a running total `summ` for the current sequence, and if `summ == k`, we increment our answer `cnt`.
- **Time Complexity**: $O(N^2)$ because we check the sum for every possible starting and ending combination of a subarray. This will likely result in a Time Limit Exceeded (TLE) error for large arrays.
- **Space Complexity**: $O(1)$ since we only use a couple of variables to keep track of sums and counts.

### 2. Prefix Sum with Hash Map (Optimal)
- **Concept**: We can significantly speed this up using a Hash Map and the concept of a Prefix Sum (cumulative sum). 
  - Imagine `cum_sum` is the total sum of all elements from index `0` up to the current index `j`. 
  - If there is a subarray ending at index `j` and starting at some index `i` whose sum is `k`, it means the prefix sum up to index `i-1` must have been `cum_sum - k`.
  - Therefore, at any point, we just need to check: *"Have I ever seen a prefix sum equal to `cum_sum - k` in the past?"* If we have, every time we saw it represents a valid subarray ending at our current index.
- **Implementation**:
  - We use a dictionary `see_in_past` to store the frequency of all prefix sums we've encountered (`prefix_sum -> frequency`).
  - **Crucial Step**: We initialize `see_in_past[0] = 1`. This handles the case where a valid subarray starts exactly at index `0` (meaning `cum_sum` itself exactly equals `k`, so `cum_sum - k = 0`).
  - As we iterate through the array, we continually add elements to `cum_sum`.
  - We check if `(cum_sum - k)` exists in `see_in_past`. If it does, we add its frequency to our `result` count.
  - Finally, we update the frequency of our current `cum_sum` in the dictionary.
- **Time Complexity**: $O(N)$ because we only pass through the array once, and dictionary insertions/lookups take $O(1)$ on average.
- **Space Complexity**: $O(N)$ in the worst case, because we might store every cumulative sum in the dictionary if they are all unique.

## Code
```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        
        # Using Prefix Sum with Hash Map (Optimal)
        see_in_past = {}
        cum_sum = 0
        result = 0
        
        # Base case: A sum of 0 has occurred exactly once before we even start
        see_in_past[0] = 1 
        
        for i in range(len(nums)):
            cum_sum += nums[i]
            
            # If (cum_sum - k) was seen before, it means a valid subarray exists
            if (cum_sum - k) in see_in_past:
                result += see_in_past[cum_sum - k]
                
            # Store/Update the current cumulative sum frequency in the hash map
            see_in_past[cum_sum] = see_in_past.get(cum_sum, 0) + 1
            
        return result
```
