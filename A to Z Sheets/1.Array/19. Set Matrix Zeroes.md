# 73. Set Matrix Zeroes

**Difficulty:** Medium  
**Topics:** Array, Hash Table, Matrix  
[LeetCode Link](https://leetcode.com/problems/set-matrix-zeroes/)

## Problem Description
Given an `m x n` integer matrix `matrix`, if an element is `0`, set its entire row and column to `0`'s.
You must do it **in place**.

### Examples

**Example 1:**
- **Input:** `matrix = [[1,1,1],[1,0,1],[1,1,1]]`
- **Output:** `[[1,0,1],[0,0,0],[1,0,1]]`

**Example 2:**
- **Input:** `matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]`
- **Output:** `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]`

---

## Concepts & Explanation: Three Approaches

### 1. Brute Force Approach
- **Intuition**: The simplest way to avoid incorrectly cascading zeros (where a newly placed zero triggers another row/col to become zero) is to work with a separate copy of the matrix.
- **Approach**: Create a full copy of the original matrix called `temp_mat`. Iterate through the original `matrix`. Whenever you encounter a `0`, go into `temp_mat` and change that entire row and column to `0`s. Finally, overwrite the original `matrix` with `temp_mat`.
- **Time Complexity**: $O((N \times M) \times (N + M))$. For every cell, if it is 0, we traverse its entire row and column. This is highly inefficient.
- **Space Complexity**: $O(N \times M)$ because we are making a complete separate copy of the matrix.

### 2. Better Approach (Using Additional Arrays)
- **Intuition**: We don't need a full copy of the matrix. We only need to know *which* rows and *which* columns are supposed to be zeroed out.
- **Approach**: Create two boolean arrays: `row` of size `m` and `cols` of size `n`, initially all `False`.
  - **Pass 1**: Traverse the matrix. If `matrix[i][j] == 0`, set `row[i] = True` and `cols[j] = True`.
  - **Pass 2**: Traverse the matrix again. For any cell at `(i, j)`, if `row[i]` is True OR `cols[j]` is True, set `matrix[i][j] = 0`.
- **Time Complexity**: $O(N \times M)$ as we traverse the matrix twice.
- **Space Complexity**: $O(N + M)$ to store the `row` and `cols` arrays.

### 3. Optimal Approach (In-Place Markers)
- **Intuition**: To achieve $O(1)$ space, we can use the **first row** and **first column** of the matrix itself as our tracker arrays! However, because they overlap at `matrix[0][0]`, we need to first check if the first row or first column inherently needs to be zeroed out and store that in two boolean variables.
- **Approach**: 
  1. Check if there are any zeros in the very first row and set `firstRowImpacted = True`. Do the same for the first column, tracking `firstColImpacted`.
  2. Traverse the *inner* matrix (from row 1 and col 1). If `matrix[i][j] == 0`, mark `matrix[i][0] = 0` (marking the row) and `matrix[0][j] = 0` (marking the column).
  3. Traverse the *inner* matrix again. If the row marker or column marker is `0`, set `matrix[i][j] = 0`.
  4. Finally, if `firstRowImpacted` is True, zero out the entire first row. If `firstColImpacted` is True, zero out the entire first column.
- **Time Complexity**: $O(N \times M)$ to traverse the matrix a few times.
- **Space Complexity**: $O(1)$ because we only use two boolean variables and reuse the matrix's own memory for tracking.
