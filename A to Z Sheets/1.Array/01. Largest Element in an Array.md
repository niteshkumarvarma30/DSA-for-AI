# Largest Element in an Array

## Concepts
- **Iteration**: We iterate through each element of the array to find the maximum value.
- **Initialization**: We initialize the `max_element` with negative infinity (`float('-inf')`). This ensures that the first element compared will always be larger and update the `max_element`.
- **Comparison**: The `max()` function is used to compare the current element with the maximum element found so far, updating it if a larger value is found.
- **Time Complexity**: $O(N)$ because it visits every element in the array exactly once.
- **Space Complexity**: $O(1)$ because it only uses a few variables regardless of the size of the array.

## Code
```python
class Solution:
    def largest(self, arr):
        # code here
        n = len(arr)
        max_element = float('-inf')
        for i in range(n):
            max_element = max(max_element, arr[i])
            
        return max_element    
```
