# Two Sum

## Concepts & Explanation
The goal of this problem is to find two numbers in an array that add up to a specific `target` value, and return their indices. We are guaranteed that there is exactly one solution.

The provided code demonstrates two different approaches to solving this problem:

### 1. Hash Map / Dictionary Approach (Optimal)
- **Concept**: Instead of checking every possible pair, we can use a Hash Map (dictionary in Python) to "remember" the numbers we have seen so far along with their indices. As we examine each number `nums[i]`, we calculate the complement needed to reach the target: `remaining = target - nums[i]`. We then simply check if we have already seen this `remaining` number.
- **Implementation**: 
  - We initialize an empty dictionary `my_dict`.
  - We loop through the array using index `i`. For each element, we calculate the `remaining` value.
  - We check if `remaining` exists as a key in `my_dict`. 
    - If it **does exist**, it means we have found a valid pair! We immediately return a list containing the index of the `remaining` number (which we retrieve via `my_dict[remaining]`) and our current index `i`.
    - If it **does not exist**, we add the current number and its index to the dictionary: `my_dict[nums[i]] = i`, so it can be paired with a future number.
- **Time Complexity**: $O(N)$ because we iterate through the array exactly once, and dictionary lookups/insertions take $O(1)$ time on average.
- **Space Complexity**: $O(N)$ in the worst case, as we might store up to $N-1$ elements in the dictionary before finding a match.

### 2. Brute Force Approach (All Possible Combinations)
- **Concept**: We can systematically check every possible pair of numbers in the array to see if their sum equals the `target`.
- **Implementation**: We use two nested loops. The outer loop `i` selects the first number, and the inner loop `j` (which always starts from `i + 1` to avoid pairing a number with itself and to avoid duplicate pairs) selects the second number. If `nums[i] + nums[j] == target`, we have found our answer.
- **Time Complexity**: $O(N^2)$ because we are checking every possible pair, resulting in a quadratic number of operations. This approach is highly inefficient for large arrays.
- **Space Complexity**: $O(1)$ since we are not using any extra space that scales with input size (excluding the returned result list).

## Code
```python
class Solution(object):
    def twoSum(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: List[int]
        """

        # Using Hash Map as dictionary (Optimal)
        n = len(nums)
        my_dict = {}
        for i in range(n):
            remaining = target - nums[i]
            if remaining in my_dict:
                return [my_dict[remaining], i]
            my_dict[nums[i]] = i
```
